# HyperMemory provider for Hermes

This provider is installed and activated by `HyperMemorySetup.exe`.

When active, Hermes automatically:

- recalls relevant local memories before every non-trivial turn;
- stores each completed non-trivial user/assistant turn;
- keeps all data in the configured local `Hyper_Memory` directory;
- continues operating if the local memory service is temporarily unavailable.

No API key, cloud account, or manual invocation is required.
