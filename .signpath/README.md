# SignPath configuration

These files are reviewable copies of the artifact configurations to enter in SignPath after the Foundation approves the project.

- `runtime-artifacts.xml`: signs the first-party API and Hermes Bridge in the GitHub artifact ZIP.
- `installer.xml`: signs the final setup executable in the second GitHub artifact ZIP.

The SignPath organization, project, policy and configuration slugs are stored as GitHub repository variables after onboarding. The API token is stored only as an Actions secret.
