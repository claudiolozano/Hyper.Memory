# Contributing

Contributions are welcome through public GitHub issues and pull requests.

- Keep all source code under the MIT license.
- Do not add proprietary binaries, credentials, personal data, or generated memory databases.
- Preserve the append-only and zero-deletion invariants.
- Run `dotnet test HyperMemory.sln -c Release` before submitting.
- Release artifacts must be produced by the repository's GitHub Actions workflow. Maintainers must not upload locally built binaries as official releases.

Security issues follow `SECURITY.md`, not the public issue tracker.
